# Relatório de Vendas Automatizado

Repositório criado para aplicar na prática os conceitos aprendidos na trilha **GitHub Foundations** (Microsoft Learn), como parte do trabalho avaliativo de Design Profissional.

## Objetivo

Este projeto é um script simples de automação que lê dados de vendas de um arquivo CSV e gera um resumo com total de vendas, média por item e o produto mais vendido — evitando o cálculo manual desses dados.

## Como executar

```bash
python relatorio.py
```

O script lê o arquivo `dados.csv` e imprime o resumo no terminal.

## O que foi aplicado do GitHub Foundations

- Criação e organização de commits com mensagens claras
- Uso de branches para desenvolver funcionalidades separadamente da branch principal
- Abertura e merge de Pull Request
- Estruturação de um README explicando o projeto

## Estrutura

- `relatorio.py` — script que processa os dados e gera o resumo
- `dados.csv` — dados de exemplo (vendas fictícias)
- `sobre.md` — descrição adicional sobre o funcionamento do projeto
