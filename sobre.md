# Sobre o projeto

Este script foi desenvolvido para demonstrar, de forma simples, como a automação pode facilitar a geração de relatórios a partir de dados brutos.

## Funcionamento

O script `relatorio.py` lê o arquivo `dados.csv`, contendo informações de produtos vendidos, e calcula:

- Total de itens vendidos
- Valor total em vendas
- Média de valor por item
- Produto mais vendido

## Possíveis melhorias futuras

- Exportar o relatório em um arquivo `.txt` ou `.pdf`
- Ler dados de múltiplas planilhas
- Gerar gráficos com os resultados
